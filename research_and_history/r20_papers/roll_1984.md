# Roll 1984 — Effective Bid-Ask Spread Estimator

**Roll, R. 1984. "A Simple Implicit Measure of the Effective Bid-Ask Spread in an Efficient Market."** *Journal of Finance* 39(4): 1127-1139.

## Core formula

$$
\hat{s} = 2 \sqrt{ \max\left( -\text{Cov}(\Delta p_t, \Delta p_{t-1}), \; 0 \right) }
$$

- `s` = effective bid-ask spread
- `Δp_t = p_t - p_{t-1}`
- 用过去 W ticks 的 sample covariance 估计

## Intuition

在有效市场 + 固定 spread 下，trade 在 bid 和 ask 之间随机弹跳（"bid-ask bounce"）→ 连续 price changes 应有**负的一阶自相关**。这个负相关的大小 = (s/2)²。

证明：假设 true price `p*_t` 是 random walk，observed `p_t = p*_t + ε_t·s/2`，ε_t ∈ {-1, +1} 等概率独立。那么 Δp_t = Δp*_t + (ε_t - ε_{t-1})·s/2，其与 Δp_{t-1} 的协方差为 `-s²/4`。

## 限制 / 实战问题

1. **Cov 经常为正**：日频股票数据，bid-ask bounce 被信息流主导，cov 频繁正 → 公式中 sqrt(-cov) 变虚数。文献常见处理：
   - 取 `max(-cov, 0)` 强制非负
   - 当 cov > 0 时返回 NaN
2. **数据频率敏感**：日频 cov 经常正；tick 频率（HFT）通常稳定负，**对我们 setup 反而是好消息**
3. **要 stationary**：需要 spread 在窗口内不变；100-tick 窗口（5 分钟）通常 OK

## 在我们 setup 下的适配

✅ 完美 stateless + sym-agnostic + 100-tick 窗口可算
- 用 W=30, 50, 100 ticks
- 输入 `Δp` 选 mid 或 close
- 当 cov > 0 时返回 0（or NaN 后填 sma 全样本均值）

```
roll_spread_W = 2 * sqrt( max( -np.cov(Δp[t-W:t], Δp[t-W-1:t-1])[0,1], 0 ) )
```

## 与已有 schema spread 的关系

- schema 已有 `spread1 = a1 - b1`（quoted spread）
- Roll 估的是 **effective spread**（实际成交平均价差），通常 < quoted spread
- **Effective/Quoted ratio** 是 liquidity quality 度量：1 = trade always at quote；< 1 = trade inside quote

→ Roll spread 不是替代品，是**互补 channel**。

## 拓展：Roll's Impact (AFML §19.3)

$$
\text{RollImpact}_W = \sqrt{ \max(-\text{Cov}(\Delta \log p_t, \Delta \log p_{t-1}), 0) } \cdot \sum_{i \in W} V_i \cdot p_i
$$

把 spread 与 dollar volume 相乘 → liquidity-aware spread
