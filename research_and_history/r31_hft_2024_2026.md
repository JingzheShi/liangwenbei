## 1. Paper Survey（2024-2026，至少 15 篇）

> 字段：**arxiv ID** ｜ **date** ｜ **核心贡献** ｜ **与我们 setup 的相关性** ｜ **是否值得复现 / 借用**

### 1.1 Foundation Models for Financial Time Series（**新范式，2025+ 集中爆发**）

#### [P1] Kronos: A Foundation Model for the Language of Financial Markets

- **arxiv:** 2508.02739（Aug 2025）
- **Authors:** Yu Shi, Zongliang Fu, S. Chen, B. Zhao, W. Xu, C. Zhang, Jian Li
- **核心:** Decoder-only autoregressive Transformer + 专用 K-line tokenizer（连续→离散），pre-train on **12B K-line 记录 / 45 全球 exchange**。Price RankIC ↑93 %，volatility MAE ↓9 %。
- **与我们 setup 相关性:** **低-中**。Kronos 在 K-line（OHLCV）粒度，**不是 sub-second LOB**。但 "把 continuous 行情 tokenize 后做 next-token prediction" 思想若我们要走 NN，可作架构灵感。
- **值得复现?** ❌（compute 成本 + 粒度不匹配）；**可借用 idea:** 把每个 sample 的 (mid-price, depth-1 vol, OFI) 离散化为 token 后做 autoregressive head。

#### [P2] FinCast: A Foundation Model for Financial Time-Series Forecasting

- **arxiv:** 2508.19609（Aug 2025）— CIKM 2025
- **Authors:** Z. Zhu, H. Chen, Q. Qu, V. Chung
- **核心:** 第一个专门面向金融 TS 的 foundation model，强调 multi-domain（stocks/commodities/futures）/ multi-resolution / **零样本可迁移**。Surpass SOTA，但论文未给出 sub-minute LOB 实验。
- **相关性:** **低**。设计粒度是 daily。
- **值得复现?** ❌

#### [P3] **Re(Visiting) Time Series Foundation Models in Finance** ⭐ — **核心读物**

- **arxiv:** 2511.18578（Nov 2025）
- **Authors:** E. Rahimikia, H. Ni, W. Wang
- **核心:** 在 **2 B 全球日收益 (94 国 × 34 年)** 上对 Chronos / TimesFM 做 zero-shot / fine-tune / from-scratch pretrain 三套 setting 严测。**最关键发现：**
  - 通用 TSFM zero-shot 上 R² = -2.80 % (TimesFM-500M)，劣于 CatBoost 的 -0.10 %
  - Fine-tune 也几乎不救
  - **从头用金融数据 pre-train** 才能爆发：Chronos-small 从 R² = -77 %（zero-shot）→ -3.18 %，加 augmentation + JKP 因子 → 41.89 % 年化、Sharpe 5.42
- **与我们 setup 相关性:** **高**。直接证伪了 "随便拿个开源 TSFM 来跑 LOB 就行" 的幻想。**支持我们 GBDT 主路线的合理性**——CatBoost/LightGBM 在金融下表现优于现成 TSFM。
- **值得复现?** ❌（不复现）；**借用结论:** 不要浪费时间试 Chronos / TimesFM zero-shot。如果要做 NN，必须 from-scratch on financial data。

#### [P4] LOBERT: Generative AI Foundation Model for LOB Messages

- **arxiv:** 2511.12563（Nov 2025）
- **核心:** BERT-style encoder-only foundation model on **message-level LOB**（add / cancel / modify / trade）。
- **相关性:** **中**。我们数据如果有 message-level（非 snapshot）则可借用 tokenization；从 task 上看是 representation pretraining（不是直接给 directional 信号）。
- **值得复现?** ❌（自身 pretraining 太重）；**借用 idea:** 把 (event_type, price_level_relative_to_mid, size) 三元组做 token，feed 进 LightGBM as count/embedding aggregate。

### 1.2 LOB-Specific Generative & Simulation（2024-2026）

#### [P5] LOB-Bench: Benchmarking Generative AI for LOB Data ⭐

- **arxiv:** 2502.09172（Feb 2025）
- **Authors:** Nagy / Frey / Li / Sarkar / Vyetrenko / Zohren / Calinescu / Foerster
- **核心:** 第一个 **distributional** LOB 生成 benchmark。比较 LOBS5 (35M S5) / RWKV4&6 (170M) / cGAN / parametric。结论：**LOBS5 (state-space) 全面赢**；**所有 generative 模型 horizon 加长后剧烈漂移**（"model derailment"）。
- **相关性:** **中**。我们不做 simulation，但 derailment 现象提示：**短 horizon（h_10）信号比长 horizon（h_60）干净**。
- **值得复现?** ❌；**借用 idea:** discriminator-based eval（real vs synthetic ROC）作为 backtest 信号是否被市场识破的代理。

#### [P6] DiffLOB: Diffusion Models for Counterfactual LOB Generation

- **arxiv:** 2602.03776（Feb 2026）
- **Authors:** Z. Wang, C. Ventre
- **核心:** Regime-conditioned diffusion，conditioning on (trend, vol, liquidity, OFI) 后 sample 反事实 LOB 轨迹。三层 eval：Controllable Realism / Counterfactual validity / Counterfactual usefulness。
- **相关性:** **低**。是 simulation/stress-test 工具，不是 directional predictor。
- **值得复现?** ❌

#### [P7] TradeFM: Generative Foundation Model for Trade-flow ⭐

- **arxiv:** 2602.23784（Feb 2026，submit 至 ICLR 2026）
- **Authors:** Kawawa-Beaudan / Sood / Papasotiriou / Borrajo / Veloso (J.P. Morgan AI Research)
- **核心:** **524M-param** generative Transformer，trained on **Level-3 trade messages of >9K equities**。**关键创新：scale-invariant features + universal tokenization** —— 不依赖资产特异性 calibration（**这是我们 sym-agnostic 约束的天然朋友**）。比 Compound Hawkes 误差降 2-3×；零样本迁移到 APAC OOD market。
- **与我们 setup 相关性:** **高**。`scale-invariant features` 思想直接对应我们 "sym-agnostic feature engineering" 的方向。"Universal tokenization eliminates asset-specific calibration" = 我们禁用 sym embedding 的更激进版本。
- **值得复现?** ❌（524M 参数 + 9K equities 不可复现）；**强烈建议借用：** 阅读 paper 的 "scale-invariant features" 章节，看能否抽取 1-3 个特征构造为我们 LightGBM 输入。
- **详细笔记:** [`r31_papers/tradefm_2026.md`](r31_papers/tradefm_2026.md)

#### [P8] MDQR: Multidimensional Deep Queue-Reactive

- **arxiv:** 2501.08822（Jan 2025）
- **Authors:** H. Bodor, L. Carlier
- **核心:** 扩展经典 Queue-Reactive，relax queue independence + 加 market features + NN-based order-size distribution。Reproduce square-root impact law。
- **相关性:** **低**。Simulation 工具。
- **值得复现?** ❌

### 1.3 LOB Architectures — 2024-2025 新模型

#### [P9] TLOB / MLPLOB ⭐

- **arxiv:** 2502.15757 v3（Feb 2025 → May 2025）
- **Authors:** L. Berti et al.
- **核心:** 同 paper 出 **2 个模型**：
  - **MLPLOB** — 纯 MLP，**居然在 FI-2010 / Tesla / Intel / 2023-Bitcoin 上超过 DeepLOB / BiNCTABL** 的 F1。简单 = SOTA。
  - **TLOB** — Dual-attention Transformer：**Temporal Self-Attention** + **Feature Self-Attention** 因子化（避免 O(LF)² 复杂度）。FI-2010 +3.7 F1。
- **相关性:** **高**（NN 路线）。Berti 2023 已在 `papers/model_lob_benchmark_briola_2023.md`，但 TLOB/MLPLOB 是 v3 (May 2025) 之后的扩展，**MLPLOB 的简单性论证**值得我们尝试——若我们 GBDT 之上想试 NN，**先试 MLPLOB（不是 TLOB）**。
- **值得复现?** ✅（MLPLOB 易实现），中等优先级 (T31 候选)
- **详细笔记:** [`r31_papers/tlob_mlplob_berti_2025.md`](r31_papers/tlob_mlplob_berti_2025.md)

#### [P10] HLOB: Homological Convolutional NN ⭐

- 期刊：Expert Systems with Applications（Dec 2024）
- **核心:** 用 **homological complex (TDA)** 把 LOB volume levels 之间的依赖结构嵌入 conv 层，捕捉 non-trivial 跨 level 关系。
- **相关性:** **中**。Topology-aware 输入对我们 LightGBM 太重；但 idea = 同一 snapshot 内多 level 之间的非邻近关系；可用 lightweight 替代：**(L1−L2, L2−L3, ...) volume-cascade differences** 作 explicit feature。
- **值得复现?** ❌（HLOB 本身），**借用 idea:** ✅。可加入 8-10 条 cross-level cascade features。

#### [P11] Siamese LOB (Yang et al. 2025)

- **arxiv:** 2505.22678（May 2025，data 2021）
- **核心:** 用 **bid-ask 对称性** 设计 Siamese arch：bid 侧、ask 侧用 weight-shared sub-net 编码后取差，作为 head 输入。证实在 OFI 输入下相对 baseline 改进 75 %+ cases。
- **相关性:** **中**（NN）。
- **值得复现?** ⚠️（NN only），**借用 idea:** 我们 GBDT 也可强制 "对称特征" — 把所有 ask-side feature 取负号后与 bid-side feature 一起送入（让模型学到对称性），或显式构造 (bid_x - ask_x) 的 12-20 条新 feature。

#### [P12] Attention-Based Reading-Highlighting-Forecasting LOB

- **arxiv:** 2409.02277（Sep 2024）
- **Authors:** J. Jung, K. Lee (Purdue)
- **核心:** Encoder-decoder Transformer + **compound multivariate embedding**（per-LOB-attribute embedding）+ **structural regularizer**（best_bid < mid < best_ask 排序违反惩罚）。Multi-level forecast 而非 mid-only。
- **相关性:** **中**。**Structural regularizer**: 强制 prediction 满足金融排序约束 — 我们 multi-class softmax (down/flat/up) 的 logit 也可加 ordinal regularizer（log-prob ordered: P(down) > P(flat) for negative-Δp samples）。
- **值得复现?** **NN regularizer ✅（如果走 NN）**；GBDT 借不到（softmax 已是 unconstrained）。

#### [P13] Multi-Horizon LOB Forecasting (Zhang & Zohren 2021, IPU)

- **arxiv:** 2105.10430（已 R20 / model_multihorizon_deeplob 覆盖，仅放此作 anchor）

### 1.4 Hybrid econometric × NN（实用性高）

#### [P14] Hybrid VAR + FNN for OFI Prediction ⭐

- **arxiv:** 2411.08382（Nov 2024）
- **Authors:** A. Rahman, N. Upadhye (IIT Madras)
- **核心:** 两阶段：(1) VAR (lag=2) 拟合 OFI 线性结构 → (2) FNN 32-64-2 学 VAR residual 中的非线性。在 BTCUSD/ETHUSDT 上 R² = 0.997 / 0.983；trading accuracy 96-98 %。
- **相关性:** **高**。这套 "线性 backbone + GBDT-on-residual" 思路 **完美适用** 我们：
  - LightGBM 已是非线性，可换形式 → **先用 OLS / Ridge (5-10 维 OFI lag) 算 ŷ_lin**，再让 LightGBM target = (y_true − ŷ_lin)
  - 优势：(1) 减少 LightGBM 学线性部分的方差；(2) 推理时把 ŷ_lin 加回；stateless 兼容
- **值得复现?** ✅ 中等优先级（与 ensemble stacking 不冲突，可叠加）
- **详细笔记:** [`r31_papers/hybrid_var_fnn_ofi_2024.md`](r31_papers/hybrid_var_fnn_ofi_2024.md)

#### [P15] Forecasting OFI via Hawkes Process

- **arxiv:** 2408.03594（Aug 2024）
- **Authors:** A. Anantha, S. Jain (IISc / SigmaQuant)
- **核心:** 双变量 Hawkes（buy/sell 自激+互激）+ exp 核 + Monte Carlo（500 rollouts/min）→ 1-min ahead OFI **distribution**（不只是 point）。Markovian exp kernel 很高效。
- **相关性:** **中**。我们 horizon 是 h_10 / h_60（毫秒至 ~分钟），可与 paper 的 1-min target 同尺度。Distribution 输出可与 NGBoost 串。
- **值得复现?** ⚠️（Hawkes 实现 + 推理时间，不太适合 stateless ms 级响应）；**借用 idea:** 用经验 buy/sell event-arrival rate (per-snapshot) 作 feature。

#### [P16] Order Book Filtration (Anantha et al. 2025) ⭐⭐

- **arxiv:** 2507.22712（Jul 2025）
- **Authors:** Anantha / Jain / Maiti
- **核心:** 三套 **可观测、实时、stateless** noise filter:
  1. **Lifetime filter ℱ_T**: 删掉 lifetime < threshold 的报价
  2. **Modification-count filter ℱ_M**: 删掉被频繁改单的报价
  3. **Modification-time filter ℱ_M̃**: 删掉密集 last-second 改单
  Filter 完后 OBI / OFI 的 Pearson r 提升、regime 分类提升；Hawkes 因果激励 limited gain。
- **相关性:** **极高**。**直接对应我们 EDA 看到的 fleeting-quote 噪声**。如果数据有 lifetime 字段就直接上；没有就用 update-count 近似。
- **值得复现?** ✅✅ **Top-3 推荐**（见 §0）
- **详细笔记:** [`r31_papers/order_book_filtration_2025.md`](r31_papers/order_book_filtration_2025.md)

### 1.5 Distribution Shift / OOD（与我们 LOSO 强相关）

#### [P17] ReVol: Return-Volatility Normalization ⭐⭐

- **arxiv:** 2508.20108 v2（Aug 2025）
- **Authors:** H. Lee, J. Jeon, J. Hong, U. Kang (SNU)
- **核心:** 用 **GBM-启发的 closed-form 变换** 把 raw price → ε（μ̂ + σ̂ 是 sample-level 估计），把 sample 间 mean/var/skew/kurt 都对齐。三模块 (RVN / RVE attention-LSTM 估 μ̂ σ̂ / RVD)。在 US/CN/UK/KR 跨市场上 IC + 0.03、Sharpe + 0.7。
- **相关性:** **极高**（LOSO + cross-stock）。**注意硬约束：** 估 μ̂/σ̂ 必须只用过去窗口，**不可用 cross-sample**。
- **值得复现?** ✅✅ **Top-1 推荐**（见 §0）。
- **详细笔记:** [`r31_papers/revol_lee_2025.md`](r31_papers/revol_lee_2025.md)

#### [P18] APT: Affine Prototype-Timestamp

- **arxiv:** 2511.12945（Nov 2025）
- **核心:** Lightweight model-agnostic plug-in，learns affine prototype per timestamp，适配 distribution shift。
- **相关性:** **中**。值得后续阅读但 priority 低于 ReVol（更新更近、empirical 更有说服力）。
- **值得复现?** 低优先级。

#### [P19] TimeAlign: Distribution-Aware Alignment

- **arxiv:** 2509.14181（Sep 2025）
- **核心:** Source-target distribution alignment for TS forecasting。
- **相关性:** 低-中。我们没有"source domain → target domain"的强结构（all syms 是同一 batch 训练）。

#### [P20] JointPGM: Intra/Inter-Series Transitional Shift

- **arxiv:** 2407.13194（Jul 2024）
- **核心:** PGM 显式分解 intra-series 和 inter-series 的非平稳。MAE -15.3 %，MSE -37.9 %。
- **相关性:** **中**。Inter-series component 对 cross-sym OOD 有用，但实现复杂（PGM + Gumbel-softmax + Fourier）。
- **值得复现?** ❌（cost vs ReVol）。

### 1.10 Benchmark / Resource

## 3. Top 5 推荐 + 实施 Roadmap（7-14 天）

> 与 R10 / R13 / R12 / R11 的实施序列**互补**，不冲突。每项独立 ablation。

### 🥇 Priority 1: ReVol Normalization (P17)

- **代码:** 在 `build_features.py` 的 cache 阶段加 `revol_normalize(price_seq, vol_seq)`：
  ```python
  # 仅用过去 window=64 的 log-return 估 μ̂,σ̂ (causal, stateless)
  log_ret = np.log(price[1:] / price[:-1])
  mu_hat, sigma_hat = log_ret.mean(), log_ret.std() + 1e-6
  eps_t = (log_ret - mu_hat) / sigma_hat
  # eps_t 替代 raw return 作 LightGBM 输入
  ```
- **Day 1**: 实现 + unit test (correctness on synthetic GBM)
- **Day 2**: full feature build + 5-seed CV + LOSO 测
- **预期:** LOSO h_10 + 3 ~ + 8

### 🥈 Priority 2: Order Book Filtration (P16)

- **代码:** 在 raw LOB 数据预处理阶段：
  - 如果有 `order_lifetime_ms` 字段：构造 `OFI_filtered = OFI(orders[lifetime > 50ms])`
  - 如果只有 snapshot：用 update-count 近似（每个 best-bid/ask 跳动次数）
  - 加 8-12 条 filtered features
- **Day 3-4**
- **预期:** + 1 ~ + 5

### 🥉 Priority 3: Savitzky-Golay Smooth Features (P10)

- **代码:** `scipy.signal.savgol_filter(x, window=9, polyorder=3, mode='nearest')` (causal mode)
- 把每个 continuous LOB feature（mid, OFI, OBI, depth_imbalance, ...）**生成一份 SG-smooth 副本**作为额外 feature
- **Day 5**
- **预期:** + 1 ~ + 3

### 🏅 Priority 4: Volatility-Conditional MoE (P23)

- **代码:** 训 2 个 LightGBM：
  - `lgb_high` on samples with `realized_vol_30s > p70`
  - `lgb_low` on samples with `realized_vol_30s ≤ p70`
- 推理：calc 当下 sample 的 realized_vol → soft gate `w = sigmoid((vol - vol_p70) / scale)` → ŷ = w · ŷ_high + (1-w) · ŷ_low
- 完全 stateless（gate 是 sample-wise 函数）
- **Day 6-7**
- **预期:** + 1 ~ + 4

### 🏅 Priority 5: Multi-Class Isotonic NA-FIR (P26)

- **代码:** 在 R13 D（z-gate）之前加一层 NA-FIR isotonic on val set's softmax output
- **Day 8**
- **预期:** + 0.5 ~ + 2（叠加 R13 D）
