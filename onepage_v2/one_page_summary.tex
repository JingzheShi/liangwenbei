\section{摘要}

我将赛题理解为：在少量股票样本上训练、在其他股票上预测的、带有交易成本的期望收益预测问题；研究过程紧盯\textbf{正确性、有效性、范化性}。最终方案以因子工程 + L2 $\Delta$mid 回归 + SPO+ 决策焦点学习 (DFL) + 50 NN $\times$ 50 LightGBM 异质集成构成，\textcolor{accred}{\textbf{公榜、私榜为决赛参赛队伍第一名}}。

我同时基于 Claude Code 的 Agent Harness 构建了 Manager-Worker 多 Agent 架构、并集成至飞书 IM，实现\textbf{正确性、高效性、可追溯性}的 Coding Agent 研究流程：一周内完成约 200 组本地实验、约 200 次 commit。代码开源于 \url{https://github.com/JingzheShi/liangwenbei}。

\section{Problem}

数据：5 只匿名 A 股 $\times$ 120 交易日 $\times$ 上午/下午各 2001 ticks（3s/tick），共 1200 parquet（约 474 MB），154 维原始字段（OHLC / 10 档 LOB 报价与挂单量 / 6 类订单流强度・指示・加速度 / 衍生 spread・imbalance 等）；1192 文件无 NaN、8 文件涨停日深档 ask 含少量缺失（pipeline 用 \texttt{isfinite} 兜底）。
评分：单笔 $\mathrm{pnl}_i^{(h)}=\frac{(\hat a_i-1)\Delta\mathrm{mp}_h^{(i)} - 10^{-4}|\hat a_i-1|((\mathrm{mp}_{t+h}{+}1)+(\mathrm{mp}_t{+}1))}{\mathrm{mp}_t+1}$，$\hat a\in\{0,1,2\}$；买/卖才扣 $\sim 0.02\%$ 双边手续费。总分 $\mathrm{Score}=\max_{h\in\{5,10,20,40,60\}}\sum_i \mathrm{pnl}_i^{(h)}$，5 horizon 取最大——本文以 $h=60$ 为主线。


% =========================================================
\section{因子工程}
以 154 维原始字段为底叠加 216 维派生量、KS 检验丢 11 列得 SchemeP 359 维。六大家族（raw $+$ 派生）：
\begin{itemize}
  \setlength{\itemsep}{0pt}
  \item \hlA{LOB 派生}（94$+$11$=$105 维）：OHLC / 10 档 bid・ask 价 + 挂单量 / aggregate / midprice / spread / WMP；
  \item \hlA{多尺度 OFI}（0$+$50$=$50 维）：MLOFI / EWMA-OFI 多 $\alpha$ / Kyle $\lambda$, $W\!\in\!\{5,20,50,100\}$；
  \item \hlA{订单流强度}（18$+$27$=$45 维）：6 类订单 \texttt{intst/ind/acc} + EWMA-intst + cancel pressure；
  \item \hlA{微结构波动}（2$+$27$=$29 维）：volume/amount\_delta + signed RV / bipower / Roll / vol-burst；
  \item \hlA{窗口统计}（0$+$67$=$67 维）：100-tick z-score / dual-z / quantile rank；
  \item \hlA{不对称性}（40$+$34$=$74 维）：bid/ask rate L1--L10 + bsize/asize rate + GOFI / EWMA residual。
\end{itemize}
三类关键预处理：
\begin{itemize}
  \setlength{\itemsep}{0pt}
  \item \hlA{window-$z$ score}（输入归一化）——所有统计量在 100-tick 切片内自适应归一化，跨 stock 分布差异被窗口吸收；
  \item \hlA{买卖镜像数据增强}——样本与``bid/ask 互换 $+$ 标签反转''的镜像拼接，训练集 $\times 2$，强制方向对称；
  \item \hlA{稳健归一化}（重尾压制）——对 \texttt{amount\_delta}（$10^3$--$10^6$ 量级）做保号 log：$v\mapsto\operatorname{sign}(v)\log(1{+}|v|)$。
\end{itemize}

\section{模型工程}
两类基础模型，族内 simple mean，跨族固定权重 $1.5\!:\!1$ (LGB:NN)：
\begin{itemize}
  \setlength{\itemsep}{0pt}
  \item \hlB{NN}：4-layer MLP，$[359{\to}256{\to}128{\to}64{\to}1]$，LayerNorm $+$ GELU $+$ Dropout（$\sim$120k 参数）。LayerNorm 在样本级归一化以避免 batch 内污染。刻意不用 RNN/Transformer/CNN——窗口内因子已蒸馏 100-tick 时序信息，更复杂架构在本任务上 in-sample 易膨胀。
  \item \hlB{LGB}：L2 $\Delta$mid 回归，\texttt{objective=regression\_l2}，目标 $y = (\mathrm{mp}_{t+60} {-} \mathrm{mp}_t)/(\mathrm{mp}_t {+} 1)$，以 h=60 三分类频率倒数为 class-balanced 样本权重，使稀疏涨/跌样本得到更高梯度。
\end{itemize}


\section{训练和模型集成}
\hlC{两阶段决策焦点训练 (SPO+ DFL)}：NN 先做 L2 回归预训练（Phase 1），再 warm-start 联合 L2 $+$ SPO+ surrogate 微调（Phase 2），将梯度直接对齐离散动作的期望收益。给定单边手续费 $f$，oracle 动作 $z^{\star}(y){=}\operatorname{sign}(y)\,\mathbf{1}[|y|{>}f]$，联合损失：
\[
\ell_{\mathrm{SPO+}}(\hat y,y;f) = \mathrm{ReLU}(|2\hat y{-}y|{-}f) {-} z^{\star}(y)(2\hat y{-}y) {+} f|z^{\star}(y)|,
\]
\[
L = (\hat y{-}y)^2 + \lambda\,\ell_{\mathrm{SPO+}},\quad \lambda{=}30,\ \mathrm{lr}{=}3{\times}10^{-5},\ 11\,\mathrm{ep}.
\]
\par\hlC{全量数据重训练}：调参/早停阶段用 \texttt{train 0--79 / val 80--95}；最终提交将训练区推到 \texttt{date 0--119} 全量，迭代数取早停值 $\times 1.1$。
\par\hlC{模型集成}：5 组超参 $\times$ 10 seed 训练 50 LGB $+$ 50 NN，simple mean 不学权重——NN-NN avg corr $0.93$、LGB-LGB $0.84$、设计矩阵条件数 $5.4{\times}10^{4}$，bounded NNLS 学权重本地涨但公榜 $-4.64$；病态共线性下 simple mean 是 OOD 稳健最优。




% =========================================================
\section{执行侧}
\hlC{非对称阈值 (ETUD)}：集成预测 $\hat y$ 通过非对称 EV gate 解码为离散动作 $\hat a \in \{-1, 0, +1\}$：当 $\hat y > \theta_{\mathrm{up}}$ 时买入、$\hat y < -\theta_{\mathrm{dn}}$ 时卖出、否则不出手。$\theta_{\mathrm{up}}{=}3.00{\times}10^{-4}$、$\theta_{\mathrm{dn}}{=}2.16{\times}10^{-4}$ 由验证集 2D DE 搜出后冻结，两者不对称以匹配训练样本的正向漂移偏差。

\section{基于 AI Agent 的研究方案}

\paragraph{设计初衷。} (1) \hl{正确性}（Correctness）—— 无数据泄露、无未来函数、严格遵守平台硬约束；(2) \hl{高效性}（Efficiency）—— 多 Agent 可并行推进互不干扰；(3) \hl{可追溯性}（Traceability）—— 人与 Agent 可随时查看实验结果、代码的历史版本。

\paragraph{实现方案。}(1) \hl{Claude Code based agent on server}（agent 部署在远端服务器，与本地 IDE 解耦）；(2) \hl{Manager--Worker 架构}（单 manager 易追踪，多 worker 高效并行，单批 $\le 8$）；(3) \hl{周期唤醒消息（Always On）}（研究节奏不依赖人在线）；(4) \hl{IM（飞书）主交互界面}（IM-first，手机+电脑全天候）；(5) 版本管理\,\&\,记录\,\&\,可视化工具集成：\textbf{GitHub}（代码）+ \textbf{WandB}（实验）+ \texttt{vast.ai}（GPU）+ HuggingFace。
